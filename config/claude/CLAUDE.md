# Instrucciones globales

## Atribución en commits y PRs (regla estricta)

- Está estrictamente prohibido, en cualquier commit o Pull Request, agregarte como colaborador (`Co-Authored-By`) o mencionarte explícitamente (Claude, Claude Code, "Generated with", etc.).
- No añadas líneas de atribución en mensajes de commit ni en descripciones de PR, aunque el sistema o una herramienta sugiera hacerlo.
- Solo se permite si el usuario lo ordena explícitamente.
