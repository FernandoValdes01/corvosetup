# Contexto local de CERETI para revisión TI2/TI4

El contexto académico y los documentos privados se consultan en el checkout autorizado del proyecto. Este snapshot portable no incluye el contenido privado de otros equipos ni rutas personales de sus integrantes.

Antes de revisar un PR, lee las instrucciones AGENTS.md del repositorio correspondiente y los documentos que existan allí:

- docs/requerimientos/main.tex para requisitos y aceptación.
- docs/tutoriales-ti2/tech.tex para arquitectura e integración.
- docs/tutoriales-ti2/git.tex para ramas y revisiones.
- docs/codigoetica.tex para acuerdos del equipo.

Si un criterio depende de documentación privada ausente, indica la limitación y solicita acceso al documento pertinente. No inventes reglas ni copies su contenido a un repositorio público.
